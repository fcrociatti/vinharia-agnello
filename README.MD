# Vinheria Agnello

Sistema básico para cadastro e análise de vinhos artesanais da Vinheria Agnello.

## Sobre o projeto

Projeto desenvolvido como Checkpoint 1 da disciplina de Web Development do curso de Engenharia de Software da FIAP, turma 1ESPS.

O sistema solicita ao usuário as informações de um vinho (nome, tipo, safra e quantidade em estoque) por meio de `prompt()`, avisa o usuário com `alert()` e exibe os detalhes organizados no console do navegador com `console.log()`.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
